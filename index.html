개발자 관점에서 보는 엑셀 함수

함수 = 메서드

엑셀 함수는 프로그래밍의 메서드/함수와 동일합니다. SUMIF(range, criteria, sum_range)는 sumIf(range, criteria, sumRange)와 같습니다.

절대참조 = 상수

$A$1은 상수(constant)처럼 고정된 값입니다. 셀을 복사해도 변하지 않습니다.

상대참조 = 변수

A1은 변수(variable)처럼 셀 위치에 따라 상대적으로 변합니다.

피벗 테이블 = GROUP BY

피벗 테이블은 SQL의 GROUP BY + 집계 함수(sum, count, avg)와 같은 개념입니다.

1. 조건부 집계 함수 (SQL의 WHERE + GROUP BY)

SUMIF

구문: SUMIF(범위, 조건, 합산범위)

SQL 비유: SELECT SUM(컬럼) FROM 테이블 WHERE 조건

// 예시: A열이 "과일"인 경우 B열 합계
=SUMIF(A1:A10, "과일", B1:B10)

실수 포인트: 매개변수 순서 (범위, 조건, 합산범위)

자주 출제 실수 다발

COUNTIF

구문: COUNTIF(범위, 조건)

SQL 비유: SELECT COUNT(*) FROM 테이블 WHERE 조건

// 예시: A열이 "합격"인 개수
=COUNTIF(A1:A10, "합격")

실수 포인트: 조건에 따옴표 사용 여부

자주 출제

AVERAGEIF

구문: AVERAGEIF(범위, 조건, 평균범위)

SQL 비유: SELECT AVG(컬럼) FROM 테이블 WHERE 조건

// 예시: A열이 "남"인 경우 B열 평균
=AVERAGEIF(A1:A10, "남", B1:B10)

실수 포인트: SUMIF와 매개변수 순서 동일

자주 출제

SUMIFS (다중 조건)

구문: SUMIFS(합산범위, 범위1, 조건1, 범위2, 조건2, ...)

SQL 비유: SELECT SUM(컬럼) FROM 테이블 WHERE 조건1 AND 조건2

// 예시: A열이 "과일"이고 B열이 "1월"인 경우 C열 합계
=SUMIFS(C1:C10, A1:A10, "과일", B1:B10, "1월")

실수 포인트: 합산범위가 첫 번째 매개변수!

자주 출제 실수 다발

2. 조회 함수 (SQL의 JOIN과 유사)

VLOOKUP (세로 조회)

구문: VLOOKUP(찾을값, 범위, 열번호, FALSE)

SQL 비유: SELECT 컬럼 FROM 테이블 WHERE 키 = 값

// 예시: A1 값을 B1:D10 범위에서 찾아 2번째 열 반환
=VLOOKUP(A1, B1:D10, 2, FALSE)

실수 포인트: 4번째 매개변수 FALSE (정확히 일치) 필수!

자주 출제 실수 다발

HLOOKUP (가로 조회)

구문: HLOOKUP(찾을값, 범위, 행번호, FALSE)

SQL 비유: 가로 방향 조회 (VLOOKUP의 가로 버전)

// 예시: A1 값을 B1:D10 범위에서 찾아 2번째 행 반환
=HLOOKUP(A1, B1:D10, 2, FALSE)

실수 포인트: VLOOKUP과 혼동

3. 조건 함수 (if-else문)

IF

구문: IF(조건, 참값, 거짓값)

코드 비유: if (조건) { 참값 } else { 거짓값 }

// 예시: A1이 60 이상이면 "합격", 아니면 "불합격"
=IF(A1 >= 60, "합격", "불합격")

실수 포인트: 중첩 IF 시 괄호 개수

자주 출제

IFS (다중 조건)

구문: IFS(조건1, 값1, 조건2, 값2, ...)

코드 비유: if-else if-else 문

// 예시: A1 점수에 따라 학점 부여
=IFS(A1 >= 90, "A", A1 >= 80, "B", A1 >= 70, "C")

실수 포인트: 조건 순서 (위에서 아래로 평가)

자주 출제

AND / OR

구문: AND(조건1, 조건2, ...), OR(조건1, 조건2, ...)

코드 비유: && (AND), || (OR)

// 예시: A1이 60 이상이고 B1이 80 이상이면 "합격"
=IF(AND(A1 >= 60, B1 >= 80), "합격", "불합격")

실수 포인트: AND/OR 중첩 사용 시 괄호

자주 출제

IFERROR (예외 처리)

구문: IFERROR(값, 오류시값)

코드 비유: try-catch 문

// 예시: 나누기 오류 시 "오류" 표시
=IFERROR(A1 / B1, "오류")

실수 포인트: 오류 값 설정 누락

가끔 출제

4. 텍스트 함수 (문자열 처리)

LEFT

구문: LEFT(텍스트, 문자수)

코드 비유: substring(0, n)

=LEFT("ABCDE", 3) → "ABC"

RIGHT

구문: RIGHT(텍스트, 문자수)

코드 비유: substring(-n)

=RIGHT("ABCDE", 3) → "CDE"

MID

구문: MID(텍스트, 시작위치, 문자수)

코드 비유: substring(start, end)

=MID("ABCDE", 2, 3) → "BCD"

CONCATENATE

구문: CONCATENATE(텍스트1, 텍스트2, ...)

코드 비유: 문자열 결합 (+)

=CONCATENATE("A", "B") → "AB"

LEN

구문: LEN(텍스트)

코드 비유: length()

=LEN("ABCDE") → 5

TRIM

구문: TRIM(텍스트)

코드 비유: trim()

=TRIM(" A B ") → "A B"

5. 날짜/시간 함수

TODAY

구문: TODAY()

코드 비유: new Date()

=TODAY() → 현재 날짜

NOW

구문: NOW()

코드 비유: new Date() (시간 포함)

=NOW() → 현재 날짜 및 시간

YEAR / MONTH / DAY

구문: YEAR(날짜), MONTH(날짜), DAY(날짜)

코드 비유: getFullYear(), getMonth(), getDate()

=YEAR("2024-01-15") → 2024

DATEDIF

구문: DATEDIF(시작일, 종료일, 단위)

코드 비유: 날짜 차이 계산

=DATEDIF(A1, B1, "D") → 일 수 차이
암기 팁: 함수 입력 후 반드시 괄호를 닫아야 합니다. VLOOKUP의 4번째 매개변수는 FALSE(정확히 일치)를 사용하세요. SUMIFS는 합산범위가 첫 번째 매개변수입니다!

SQL 빠른 복습 (개발자용)

이미 익숙하시죠? 빠른 복습만으로 충분합니다. 30분이면 끝!

기본 문법 (30초 복습)

-- 데이터 조회
SELECT * FROM 테이블명;

-- 조건 조회
SELECT * FROM 테이블명 WHERE 조건;

-- 데이터 추가
INSERT INTO 테이블명 VALUES (값1, 값2, ...);

-- 데이터 수정
UPDATE 테이블명 SET 컬럼명 = 값 WHERE 조건;

-- 데이터 삭제
DELETE FROM 테이블명 WHERE 조건;

-- 테이블 결합
SELECT * FROM 테이블1 INNER JOIN 테이블2 ON 조건;

-- 그룹화
SELECT 컬럼명, COUNT(*) FROM 테이블명 GROUP BY 컬럼명;

실수 다발

PPT 팁: 슬라이드 마스터 수정이 가장 중요합니다. 애니메이션과 전환 효과는 기본 설정만 확인하면 됩니다.

시험 전 체크리스트

합격 비결: 시험 전 이 체크리스트를 하나씩 확인하세요!

시험 전날

  • 공개문제(예제) 1회 이상 실습
  • 엑셀 필수 함수 15개 암기 확인
  • 피벗 테이블 생성 방법 확인
  • SQL 기본 문법 30분 복습
  • PPT 슬라이드 마스터 수정 방법 확인
  • 수험표, 신분증 준비

시험 당일

  • 시험장 30분 전 도착
  • 컴퓨터 마우스, 키보드 작동 확인
  • 시험 시작 후 문제 유형 파악
  • 시간 배분 계획 수립 (엑셀 25분, 액세스 15분, PPT 35분)
  • 문제 풀기 전 지시사항 정확히 읽기
  • 제출 전 저장 여부 확인

엑셀 체크리스트

  • 함수 입력 후 괄호 개수 확인
  • 절대참조($) 사용 여부 확인
  • 피벗 테이블 데이터 범위 확인
  • 차트 데이터 레이블 표시 확인
  • 셀 서식(숫자, 날짜) 확인

SQL 체크리스트

  • SELECT 문 작성 확인
  • WHERE 절 조건 확인
  • JOIN 조건 확인
  • GROUP BY 절 확인

PPT 체크리스트

  • 슬라이드 마스터 수정 확인
  • 애니메이션 순서 확인
  • 슬라이드 전환 효과 확인
  • 하이퍼링크 동작 확인
  • 슬라이드 번호 표시 확인
